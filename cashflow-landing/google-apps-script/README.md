# Настройка Google Apps Script с Email-уведомлениями

Скрипт [`Code.gs`](./Code.gs) обеспечивает:
1. Запись новых заявок в Google Таблицу (вкладки «Заявки Cashflow» и «Заявки WoodIQ»).
2. Мгновенную отправку красиво оформленного письма на ваш Email со всеми деталями каждой новой заявки.
3. Отдачу настроек сайта, цен и количества свободных мест в реальном времени.

---

### Как подключить за 2 минуты:

1. Откройте вашу **Google Таблицу** (к которой привязан сайт).
2. В верхнем меню нажмите: **Расширения (Extensions) → Apps Script**.
3. Скопируйте весь код из файла [`Code.gs`](./Code.gs) и вставьте в редактор Apps Script.
4. В строке **19** укажите ваш email:
   ```javascript
   const ADMIN_EMAIL = 'ваш_email@gmail.com';
   ```
5. В правом верхнем углу нажмите **Развернуть (Deploy) → Новое развертывание (New Deployment)**:
   - **Тип**: Выберите шестеренку ⚙️ → **Веб-приложение (Web app)**.
   - **Описание**: `v2 with email notifications`.
   - **Выполнять от имени (Execute as)**: `Меня (Me)`.
   - **У кого есть доступ (Who has access)**: `Все (Anyone)`.
6. Нажмите **Развернуть (Deploy)**.
   - При первом запуске Google попросит подтвердить разрешения (на доступ к Таблице и отправку Email через ваш Google-аккаунт).
7. Скопируйте полученный **URL веб-приложения** и при необходимости вставьте в файл `.env` (`VITE_URL=...`).
